# Instrucciones locales de electrónica

Las instrucciones canónicas del agente de electrónica están en [CLAUDE.md](CLAUDE.md). Este archivo existe para agentes que leen `AGENTS.md`, como Codex: leé `CLAUDE.md` completo y aplicalo igual.

Claude Code no carga este archivo mientras exista `CLAUDE.md` en esta carpeta. No agregar reglas aquí: cualquier regla nueva va en `CLAUDE.md` para que ambos agentes la vean.

Punto de entrada para personas y sesiones nuevas: [INICIAR_AQUI.md](INICIAR_AQUI.md).
