# Figuras exportadas del banco de dinámica

Esta carpeta se actualiza automáticamente al ejecutar
[`INICIAR_DINAMICA_PATA.m`](../../INICIAR_DINAMICA_PATA.m).

Archivos recomendados para compartir con el equipo:

- `resumen_equipo.png`: comparación completa de escenarios;
- `ultimo_run.png`: dashboard de la última simulación;
- `energia_solver.png`: validación energética y sensibilidad numérica.

Estas son las únicas tres salidas visuales del banco y se sobrescriben al ejecutar la acción correspondiente.
No se generan copias por escenario ni formatos auxiliares. Los datos y métricas detallados siguen disponibles
en las estructuras MATLAB retornadas por el lanzador.

Los gráficos son evidencia del banco reducido de una pata. No sustituyen la validación de la planta
completa del robot ni del CAD definitivo.
